Algorithms
HNSW
Hierarchical Navigable Small World. O(log N). Production-grade approximate search. Same algorithm as Pinecone, Weaviate, Chroma.
KD-TREE
K-Dimensional tree. O(log N) exact search. Ball-within-hyperslab pruning. Degrades in high dimensions.
BRUTE FORCE
Linear scan. O(N·d). Always exact. Baseline for correctness and benchmark comparison.
